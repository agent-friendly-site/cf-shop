给消费者的初始 prompt（Terra Pots Ceramics 陶土手作）

用法：把下面方框里的一段话复制下来，粘贴给任何一个 Agent
（Muse、Claude、Grok 都可以），不用改别的，只换一句话意图就行。

------------------------------------------------------------
我想给家里添点陶器：
https://agent-friendly-platform.refined-x.workers.dev/shops/terra-pots/
先帮我看看卖什么，再问问我主要想用来干嘛，帮我推荐一下。
------------------------------------------------------------

有预算时，加半句就够了，例如：
“我想给家里添点陶器，预算 300 元以内：
https://agent-friendly-platform.refined-x.workers.dev/shops/terra-pots/
你先问问我主要想用来干嘛，再帮我推荐，算好一共多少钱。”

小提示：
- Agent 第一轮大概率会先反问你一个问题（比如日常用、待客、
 还是装饰送礼），这是设计好的导购流程，不是没答上来。
- 不要在聊天里发银行卡号、验证码。付款走线下：确认后卖家给收款方式，你在外面付完把交易单号发给 Agent，卖家核验后发货。
- 不同客户端显示可能不同：有的有可点按钮，有的只有编号选项，
 回答内容是一样的。
